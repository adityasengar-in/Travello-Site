# 🌍 Travello  
*A clean and modern web-based travel planner built with HTML, CSS, and JavaScript.*

Travello helps users plan trips in a simple, intuitive, and visually polished way.  
Create day-by-day itineraries, organize activities, reorder plans with drag & drop, and save everything locally — all inside a fast, responsive interface.

---

## ✨ Features

### ✅ Core Functionality
- **Destination selection** (local dataset or user input)
- **Add days** to a trip effortlessly
- **Add, edit, and delete activities**
- **Day-by-day itinerary view** with clean UI cards
- **Drag & Drop** activity management  
  - Reorder activities within a day  
  - Move activities between days  
- **LocalStorage persistence** — your plans auto-save and reload
- **Mobile-friendly & responsive layout**
- **Light + Dark theme support**
